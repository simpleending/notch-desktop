# Notch 0.1.51

Closing Notch now unloads local models before the application finishes quitting. Updates are visible in the bottom-left sidebar and can install and restart through the normal save-and-close flow.

- Join local model cleanup to the application's awaited shutdown, including update restarts. Interrupt active local work and pending mounts, unload Ollama models, stop running Colibri/Strata/MLX engines, and clear manual mount pins. Skip engines that are not running; keep downloaded model files intact.
- Release loaded models when the window is hidden by optional background automation mode. Future scheduled tasks can load their selected model again.
- Show a small muted download arrow and percentage above the sidebar profile controls. When ready, replace it with an **Update** button that installs and restarts Notch.
- Keep automatic downloads enabled by default, check on startup and every six hours while open, and preserve explicit opt-outs. Ordinary quit installs a downloaded update without reopening; the Update button requests a restart.
- Preserve unsaved-work confirmation. Cancelling close cancels the pending update restart. Windows shutdown defers installation rather than attempting to relaunch.

Validation: 495 automated tests and strict type checking passed. The packaged application passed 19 update, shutdown, and mount regression tests plus native integration and 27 IPC bridge checks. The real Heretic 9B runtime unloaded successfully in about 1.5 seconds and was subsequently restored for the open application. Packaged code, installer integrity, and updater checksums were verified. No model downloads or dependency upgrades were required.

The indicator appears while downloading or when an update/action is available; it stays hidden when the installed version is current. Existing older versions receive this interface through the normal updater or this Windows installer.
