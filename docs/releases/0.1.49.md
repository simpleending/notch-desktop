# Notch 0.1.49

This release connects desktop integrations and improves local model identity and automations.

- Keep Heretic and other fine-tune identities visible in the model picker. Right-click local models to load or unload them, with accurate loaded-state feedback.
- Connect approved project MCP servers and enabled workbench MCP tools using the maintained protocol client. Connections are scoped to each turn and close on completion or cancellation.
- Let the agent search and read saved Knowledge Center notes. The existing action to start a chat with a note remains available.
- Apply isolated workspace mode consistently to Ollama, Colibri and Strata as well as OpenRouter.
- Offer opt-in tray mode for scheduling after closing the window. Explicit Quit still stops the application.
- Add file-change triggers for saved automations, with grouping, cooldown and active-run suppression. Notification clicks open the corresponding chat.
- Show the real reason an automation's selected model is unavailable.
- Update tested engine pins to Colibri 2.1.0 and Strata 0.2.13 / Control 0.1.59. Preserve weights and selections; offer validation of an existing Colibri model after its runtime changes.
- Check official engine release feeds daily, with manual checks in each engine panel. A newer untested upstream release is reported without replacing a running engine or downloading weights.
- Update the MCP client and glob/matching dependencies for current security fixes.

Validation: 466 automated tests and strict type checking passed. The actual upstream runtime controls passed launch, stop, switching and failed-start recovery with tiny engine fixtures; all test engines exited. Real catalogs and the Strata launch configuration contract were checked. No model weights were downloaded for these checks. This does not claim GPU performance benchmarking or a visual desktop walkthrough.

Background mode requires the computer to remain on and Notch to remain running in the tray. This release does not add an OS service or public webhooks. Runtime updates remain pinned to versions tested with Notch; the polling feature checks availability rather than executing arbitrary new releases.

See [integration details](../integrations-0.1.49.md) for behavior, validation boundaries and the assessment of Tencent DSpine.
