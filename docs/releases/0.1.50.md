# Notch 0.1.50

Local model mounts now stay loaded during idle time, and desktop tasks recover automatically from temporary provider failures when retrying is safe. Context sizing adapts to conversation growth before compressing history.

- Manual Ollama mounts remain loaded indefinitely. Chat and compaction requests preserve that setting, and the preference survives an app restart. Explicit unmount clears it; switching local models releases the previous engine. Closing a runtime or restarting the computer still stops its processes. Automatic, unpinned loads retain the daemon's idle policy.
- Retry temporary network errors, HTTP 408, rate limits and server errors up to three attempts with cancellable backoff. Retry the failed model request with existing tool results, without replaying completed actions. Do not automatically replay a partially displayed answer or an already dispatched tool call. Invalid credentials, invalid context, memory exhaustion and cancellation still stop immediately.
- Let Auto increase context when conversation history approaches its limit, using currently validated memory choices and the model's native limit. Keep manual context choices unchanged.
- Estimate Qwen3.5 hybrid attention memory from its layer layout and use a verified running allocation to estimate additional context memory. Retain conservative estimates for unknown layouts and avoid reclaiming integrated GPU shared memory twice.
- Aim summaries below the compression trigger, shorten oversized recent tool results while retaining their tool chain, and avoid repeating compression for unchanged history.

Validation: 483 automated tests and strict type checking passed. Live Heretic 9B at 16K answered a hello request, then recovered the exact verification phrase after one compaction (18,181 estimated history tokens reduced to 1,991). Ollama reported indefinite residency afterward. No model weights were downloaded for this release.

The packaged Windows application also passed 19 context/retry/mount regression tests, native MCP and knowledge integration checks, and all 27 model IPC bridge checks. Packaged code matched the release source, installer integrity passed, and the updater SHA-512 matched the installer. Validation used command-line checks without a visual desktop walkthrough or replacing the user's running installation.

Context and memory choices remain estimates, not performance guarantees. Auto growth checks memory again before enlarging the window. Manual context limits can still require compression on long tasks; this release reduces unnecessary compression rather than disabling it.

Implementation references: [Ollama keep-alive behavior](https://docs.ollama.com/faq#how-do-i-keep-a-model-loaded-in-memory-or-make-it-unload-immediately) and [llama.cpp Qwen3.5 layer layout](https://github.com/ggml-org/llama.cpp/blob/master/src/models/qwen35.cpp). No dependency upgrades were required.
